# 📊 Job Market Analysis using Power BI

## 📌 Project Overview

The Job Market Analysis project focuses on analyzing job postings in the Data Science and Analytics domain to identify employment trends, salary patterns, industry demand, and essential technical skills.

## 🎯 Project Objectives

* Analyze job distribution across different states.
* Identify top hiring industries and companies.
* Analyze salary trends across job titles.
* Identify the most demanded technical skills.
* Understand education requirements in the job market.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* Data Cleaning
* Data Visualization

## 📈 Key Analysis

1. State-wise Job Distribution
2. Average Salary Analysis
3. Top Industries by Job Postings
4. Company-wise Job Openings
5. Job Title Analysis
6. Technical Skills Analysis
7. Education vs Salary Analysis

## 💡 Project Outcome

This project provides insights into job market trends, salary patterns, hiring demand, and technical skills required by employers.
